# Автожурнал — учёт автомобиля на PocketBase

Приложение для учёта расходов (заправки, ТО и ремонты, страховка, запчасти), документов (СТС, ПТС, права, страховка) со сроками действия и напоминаний. Работает прямо в браузере и на телефоне (можно добавить на домашний экран), данные хранятся у вас на Synology.

## Что внутри

```
pb_public/       фронтенд (HTML/CSS/JS, сборка не нужна)
pb_migrations/   создаёт коллекции cars, records, documents, reminders
pb_hooks/        ежедневная рассылка напоминаний (09:00)
```

Нужен **PocketBase v0.23 или новее**.

## Установка на Synology (Container Manager)

1. Создайте папку, например `/volume1/docker/autojournal`, и скопируйте в неё `pb_public`, `pb_migrations`, `pb_hooks`. Рядом создайте пустую папку `pb_data`.
2. В Container Manager → Проект → Создать, вставьте `docker-compose.yml`:

```yaml
services:
  pocketbase:
    image: ghcr.io/muchobien/pocketbase:latest
    restart: unless-stopped
    ports:
      - "8090:8090"
    environment:
      # необязательно: push-уведомления через ntfy (см. ниже)
      # NTFY_URL: "https://ntfy.sh/ваш-секретный-топик"
      TZ: Europe/Moscow
    volumes:
      - ./pb_data:/pb_data
      - ./pb_public:/pb_public
      - ./pb_migrations:/pb_migrations
      - ./pb_hooks:/pb_hooks
```

   Если PocketBase у вас уже установлен — просто положите три папки рядом с его бинарником (`pb_public`, `pb_migrations`, `pb_hooks`) и перезапустите.
3. Откройте `http://IP-NAS:8090/_/`, создайте администратора. Миграция при запуске сама создаст коллекции.
4. Приложение доступно на `http://IP-NAS:8090/`. Зарегистрируйтесь — это ваш аккаунт.
5. **После регистрации закройте публичную регистрацию:** админка → Collections → users → API Rules → Create rule оставить пустым с отметкой «Set superusers only» (иначе любой в вашей сети сможет создать аккаунт).

## Доступ снаружи и на телефоне

Настройте HTTPS: DSM → Панель управления → Портал входа → Дополнительно → Обратный прокси (например `car.ваш-домен` → `localhost:8090`) и сертификат Let's Encrypt. HTTPS нужен для установки на домашний экран и браузерных уведомлений.

## Напоминания

- **В приложении:** сроки показываются на главной, в разделе «Документы» и бейджем в меню; при открытии приложения приходит уведомление браузера (включается в «Настройки»).
- **На сервере (даже когда приложение закрыто):** каждый день в 09:00 хук проверяет документы и напоминания и шлёт сообщения: за N дней до срока (поле «Напомнить за»), затем за 14, 7, 3 и 1 день, в день срока и раз в неделю после просрочки.
  - **E-mail:** админка → Settings → Mail settings → включите SMTP (например, Gmail/Яндекс с паролем приложения). Письма приходят на e-mail аккаунта.
  - **Push на телефон:** установите приложение ntfy, придумайте секретный топик и задайте `NTFY_URL` в compose (можно поднять собственный ntfy на Synology).

## Как пользоваться

- **Автомобили:** «Настройки» → «Добавить автомобиль». Переключение — выпадающий список в меню слева.
- **Фон автомобиля:** при создании или в «Настройки» → «Изменить / фон» загрузите любое фото. Фон можно убрать галочкой.
- **Документы:** раздел «Документы» → «Загрузить документ», выберите тип, срок действия и за сколько дней напомнить. Можно прикрепить несколько файлов (фото, PDF). Файлы документов закрыты: открываются только после входа.
- **Пробег** обновляется автоматически из последней записи.
- **Напоминания:** по дате и/или по пробегу (например, «замена масла при 220 000 км» — напомним за 500 км).

## Если фронтенд на другом адресе

В `pb_public/index.html` раскомментируйте строку `window.PB_URL = "https://ваш-pocketbase"` и в админке PocketBase разрешите нужный origin (по умолчанию CORS открыт).

## Резервные копии

Всё хранится в `pb_data`. Копируйте папку (Hyper Backup) или используйте Settings → Backups в админке PocketBase.

## Пробег и топливо из StarLine

Работает на сигнализациях StarLine с CAN (проверено на S96v2): сервер раз в час читает `obd_params` и обновляет пробег и уровень топлива.

1. В `docker-compose.yml` в блок `environment` добавьте:
   ```yaml
   STARLINE_APP_ID: "ваш_app_id"
   STARLINE_SECRET: "ваш_секрет"
   STARLINE_LOGIN: "почта_или_телефон_StarLine"
   STARLINE_PASS: "пароль_StarLine"
   ```
   Пересоздайте проект в Container Manager (остановить → собрать заново), чтобы переменные применились. Не публикуйте этот файл: в нём пароль.
2. Скопируйте в `pb_hooks` файлы `starline.pb.js` и `starline_lib.js`, в `pb_migrations` — `1760000200_starline.js`, и перезапустите контейнер.
3. В приложении: «Настройки» → «Изменить» у автомобиля → поле «StarLine: device_id» (значение `device_id` из вывода `starline_probe.py`).
4. На главной под одометром появится строка «StarLine: время · топливо» и кнопка обновления.

Пробег обновляется только в сторону увеличения, поэтому сбой API не уменьшит его. При ошибках смотрите журнал контейнера (строки `starline`).
